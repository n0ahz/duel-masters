When a game is created, the creator will be taken to the Game's Room.
This is a page, where the game's players can chat, and the game's creator can manage the game.
On the top panel of left side, the game's info will be displayed, e.g. if someone accepted the challenge and the status of the game.
On the bottom panel of left side, the chat will be displayed, and the players can send messages to each other. Joined users will be displayed in here.
The chat will be scrollable. Also it will show the logs which user joined and left the game room.
If a challenger accepts the challenge, the game will start.
First there will be a option for coin toss. It will be displayed in the Right panel.
When the coin toss is happening, every player will see the coin toss.
The result of the coin toss will be displayed in the Right.
Whoever wins the toss will decide who will play first. All these results and decision will be stored in the DB.
Then the game will start.

We also need a functionality to create a Deck from the selected cards. The deck will have maximum 40 cards and each card can have maximum 4 copies.
When starting the game, the game will ask the user to select the deck if there are multiple decks created by one user.
If there is only one deck, the game will start automatically.
